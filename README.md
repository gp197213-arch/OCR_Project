\# OCR Project — захват экрана + SwinIR + PaddleOCR



Автоматическое распознавание текста с выделенной области экрана.

Скрипт захватывает область, увеличивает её нейросетью \*\*SwinIR x2\*\*, распознаёт текст через \*\*PaddleOCR\*\* (русский + английский) и копирует выбранный фрагмент в буфер обмена.



\## Возможности



\- \*\*Горячая клавиша `ё`\*\* (скан-код 41, работает в любой раскладке) — запуск захвата.

\- \*\*Растягиваемая рамка\*\* — выделение области мышкой.

\- \*\*SwinIR x2\*\* — нейросетевой апскейл для улучшения качества OCR.

\- \*\*PaddleOCR\*\* — распознавание русского и английского текста с сохранением порядка строк.

\- \*\*Окно выбора\*\* — просмотр распознанного текста, выделение фрагмента, копирование в буфер.

\- \*\*Изолированное окружение\*\* — PaddleOCR работает в отдельном `venv`, не конфликтует с другими библиотеками.



\## Требования



\- \*\*Windows 10/11\*\*

\- \*\*Python 3.12+\*\*

\- \*\*NVIDIA GPU\*\* (рекомендуется) с CUDA 12.6 и cuDNN 9.5

\- \*\*Git\*\* (для клонирования SwinIR)
